# 아카펠라 성탄 찬양 메들리 — 파트별 연습 음원

원본 악보: Hanna Cho 편곡 「아카펠라 성탄 찬양 메들리」 (Finale PDF, 11쪽, 133마디)
수록곡: 고요한 밤 거룩한 밤 · 천사들의 노래가 · 천사 찬송하기를

## 음원 (`audio/`, 피아노 음색, 약 4분 50초)
| 파일 | 내용 |
|---|---|
| `00_종합_전체파트.mp3` | 5개 파트 전체 |
| `0N_연습_<파트>_강조.mp3` | 내 파트 크게 + 나머지 작게 |
| `0N_단독_<파트>.mp3` | 내 파트만 |

파트: 소프라노(01), 알토(02), 테너(03), 베이스(04), 데스캔트(05 — 54~61, 77~108, 125~130마디에만 등장)

## 반영한 악보 정보
- 템포: 시작을 ♩=78로 하고 전체를 같은 비율(78/72)로 조정
  - Adagio ♩=78 → 60~61마디 accel. → Con moto ♩≈126 → 119~120마디 molto rall. + 숨표 → Maestoso ♩≈95
  - 원본 템포(♩=72) 버전은 이전 커밋에 있음
- 조성: B♭ → C(62) → D(77) → F(91) → F#(117) → G(119), 박자 3/4 → 4/4(60)
- 셈여림(p, mp, mf, f, ff)은 음량에 반영, 크레셴도/디크레셴도는 미반영

## 기타
- `midi/` — 위 음원의 MIDI (다른 음색으로 바꾸고 싶으면 이 파일 사용)
- `score/medley_parsed.musicxml` — PDF에서 읽어낸 악보 (MuseScore로 열어 확인 가능)
- `tools/` — PDF 벡터 정보를 읽어 음표를 추출하는 스크립트
