# It's Beginning to Look a Lot Like Christmas — SATB 자동 채보 초안

원본: VOICEWING 아카펠라 영상 (52초), B장조, 약 96 BPM, 4/4

## 파일
- `score/SATB_score.pdf` — 4성부 악보 (인쇄용)
- `score/SATB_score.musicxml` — MuseScore/Finale/Sibelius에서 열어 수정 가능
- `audio/part_<파트>.mp3` — 해당 파트만 단독 재생
- `audio/practice_<파트>.mp3` — 해당 파트 크게 + 나머지 파트 작게 (연습용)
- `audio/SATB_all.mp3` — 4성부 전체
- `midi/` — 위 음원의 MIDI 원본
- `satb_transcribe.py` — 생성 스크립트 (basic-pitch 채보 → 음역/성부진행 기반 SATB 배정)

## 한계
- 자동 채보 초안이라 박자·쉼표·성부 교차 부분은 수정이 필요합니다.
- 원곡은 5인 편성이라 4파트로 줄이면서 일부 음(특히 중간 성부)이 빠지거나 섞였을 수 있습니다.
- 첫 마디(못갖춘마디) 위치는 추정값입니다.
- 가사는 포함되지 않습니다.
